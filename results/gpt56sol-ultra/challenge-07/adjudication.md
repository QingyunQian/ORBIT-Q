# Challenge 07 source-level adjudication

## Decision

The final adjudicated result is **PASS**. The original `reward.json` and
`audit-details.json` remain unchanged and continue to record the verifier's
raw failure.

## Why the raw audit was a false negative

The audit treated the ultra solution's one-time analytic branch sampling as a
different optimization objective. For this published circuit, it is an exact
reduction of the fixed-trajectory objective:

1. Every ancilla starts each layer in a computational-basis state and receives
   an `RY` rotation.
2. The following data–ancilla `RZZ` is diagonal in that basis. It changes the
   conditioned data state but not the ancilla branch probabilities.
3. The ancilla CNOT ladder is a reversible prefix XOR, so the measured bits can
   be sampled analytically from the same fixed uniforms.
4. With fixed discrete samples, the pathwise derivative of a realized branch
   with respect to its sampling angle is zero. Those ancilla angles therefore
   do not update, and the realized branches remain unchanged throughout the
   optimizer trajectory.

The ultra solution samples those invariant branches once, replaces the
conditioned diagonal interactions by exact data-register rotations, and keeps
the required TensorCircuit evolution and 100 Adam updates. It does not replace
the trajectory with one generated by different parameters.

## Independent evidence

The later Task 07 reduction campaign compared the analytic sampler against the
full 16-qubit TensorCircuit `cond_measure` program:

- all 1,024 measured bits matched;
- maximum non-ancilla gradient error was `1.5116e-6`;
- the full graph's maximum ancilla-gradient magnitude was `4.6559e-7`, while
  the exact reduced value was zero;
- the complete evaluator passed.

That study also exposed the same broader challenge-design reduction: the fixed
public workload contains only two unique eight-qubit branch circuits. See
[sxzgroup/ORBIT-Q#7](https://github.com/sxzgroup/ORBIT-Q/pull/7).

The derived comparison files therefore count Challenge 07 as valid while
retaining `raw_reward: 0`, `llm_audit_score: 0`, and
`result_status: "post_hoc_source_adjudicated"` for provenance.
